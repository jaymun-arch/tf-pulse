# TF Pulse

2026 교육혁신 성과보고서 TF 운영 허브 (정적 웹앱)

## 실행 방법

### 로컬 서버 (개발)

```bash
npm run start
```

브라우저에서 [http://127.0.0.1:5174/](http://127.0.0.1:5174/) 로 접속합니다.

또는:

```bash
python -m http.server 5174
```

### 단일 HTML (오프라인·모바일)

`TF-Pulse.html` 파일을 브라우저로 열면 서버 없이 동작합니다.

## 주요 기능

- TF 요약, 통합 일정, 취합, 공통 요청, 예산취합, 드라이브, 공통 서식
- 오늘 뭐먹지 (돌림판 · 식사담당 업체 관리 · 메뉴 투표)
- 역할별 화면 (관리자 · 예산담당 · 식사담당 · 대상자)
- 데이터는 브라우저 `localStorage`에 저장
